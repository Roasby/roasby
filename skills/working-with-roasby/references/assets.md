# Assets

Read `list_assets` first, then `preview_add_assets` with exactly one of `ad_account_id`, `campaign_id` or `ad_group_id`, or, to add the same assets to several places of one ad account in one confirmation, `campaign_ids` or `ad_group_ids` (up to 20; every asset goes to each). Tell the user when the preview warns that a sitelink goes to another site than the ads where it is linked. Roasby refuses only the assets that break a rule (`detail` names the part) and never links a second asset with the same text to the same place (`asset_exists`: offer to enable the paused one). On Google Ads every new link starts paused: once the batch is applied, offer to enable exactly those links with `preview_enable_entities` (their IDs from `list_ad_changes`). On Microsoft Ads, which cannot pause a link, Roasby links only to a paused campaign or ad group (`asset_link_would_serve` otherwise), the assets show once it is enabled, callouts show only from 2 to 20 per place, and pausing a link takes it away (enabling links it again; the asset stays). Reverting an add pauses or takes away the links it made, never the assets. A Google Ads Performance Max campaign takes assets with its `campaign_id`; other campaign types, and Performance Max on Microsoft Ads, are refused (`assets_not_on_campaign_type`).
