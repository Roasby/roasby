# Keyword research

Before you build a campaign blueprint or add keywords, use `get_keyword_research` with an `ad_account_id`, 1 to 10 `countries` as ISO codes and a `language` code. For ideas, give 1 to 20 `seed_keywords` and/or a `url` (optional `limit`); to measure the keywords you already have, give `keywords` (up to 1,000) instead. One call does one or the other, not both. It asks the account's keyword planner live (Google Ads or Microsoft Ads; ChatGPT Ads has none; Microsoft Ads researches English, French and German only). Results come in pages: `limit` keywords per page (50 by default, at most 100), `page` to read further while `has_more` is true, `total_results` for all of them. Each row has `avg_monthly_searches` (null means not enough data: say so, never 0), `monthly_searches` with one number per month of the answer's `trend_months` (null for a month without data), `competition` (Google Ads adds a `competition_index` from 0 to 100) and a bid estimate in micros of the account currency (Google Ads `low_top_of_page_bid_micros` and `high_top_of_page_bid_micros`, Microsoft Ads `suggested_bid_micros`): divide by 1,000,000 and show it in the account `currency`. The numbers are estimates and Google rounds them (more for accounts with little spend): say so, quote the numbers as given, and never invent one. Microsoft Ads has keyword data for fewer countries than it targets ads in: when it says it has none for one of the countries, try again without the countries outside its main markets, or one country at a time. Use the bid estimates to pick bids within the account's guardrails. When the answer has `status` `running`, call again with the same arguments a few seconds later; a refused request returns the same error for a few minutes, so change the request instead of repeating it; the same request within a day costs nothing, but each new one counts toward the workspace's research requests per hour, so reuse results instead of asking again with small changes. `missing_keywords` lists your keywords that came back without data.
