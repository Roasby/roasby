# Keyword research

Before you build a campaign blueprint or add keywords, find keywords people search with `get_keyword_ideas` (an `ad_account_id`, 1 to 20 `seed_keywords` and/or a `url`, 1 to 10 `countries` as ISO codes, a `language` code, optional `limit`) or measure the keywords you already have with `get_keyword_volumes` (`keywords`, up to 1,000). They ask the account's keyword planner live (Google Ads or Microsoft Ads; ChatGPT Ads has none; Microsoft Ads researches English, French and German only). Each row has `avg_monthly_searches` (null with `avg_monthly_searches_label` "Not enough data" when the platform gave no number), `monthly_searches` for the last 12 months, `competition` (Google Ads adds a `competition_index` from 0 to 100) and a bid estimate in micros of the account currency (Google Ads `low_top_of_page_bid_micros` and `high_top_of_page_bid_micros`, Microsoft Ads `suggested_bid_micros`, with `bid_label`). The numbers are estimates and Google rounds them (more for accounts with little spend): say so, quote the labels, and never invent a number. Use the bid estimates to pick bids within the account's guardrails. When the answer has `status` `running`, call again with the same arguments a few seconds later; a refused request returns the same error for a few minutes, so change the request instead of repeating it; the same request within a day costs nothing, but each new one counts toward the workspace's research requests per hour, so reuse results instead of asking again with small changes. `missing_keywords` lists your keywords that came back without data.
